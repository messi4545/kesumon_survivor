# ケスモンサバイバー (KESMON SURVIVOR)

ブラウザで手軽に遊べる、本格派2Dヴァンサバライク・ローグライクサバイバルアクション！  
迫りくる敵の大群を倒して経験値ジェムを集め、形態進化を遂げて10分間生き残り、ボスを撃破せよ！

### 🔍 各バージョンの詳細解説

#### 🌟 v1.0.0 (2026-10-28) — STAGE 2「蒼き魔海」＆桃型×口ボス軍団・完成版
- **STAGE 2「蒼き魔海」の追加**:
  - タイトル画面で「STAGE 1：機械の苔森」と「STAGE 2：蒼き魔海」を選択可能に。
  - 海中を表現した専用の動的背景シェーダー／波の揺らぎエフェクトを実装。
- **新ボス「×口桃型ボス軍団」ギミック**:
  - 桃の形をして口にバッテン（×）のついた専用グラフィックのボス。
  - **弱点部位「口」**: ×印の口以外の部位への攻撃はダメージが大幅に軽減されるため、ボスの正面・口を狙う立ち回りが重要に。
  - **小型同種の召喚**: 最大5体の小型ピーチを定期的に召喚。
  - **確定回復ドロップ**: 召喚された小型ピーチは倒すと必ずハート（回復アイテム）をドロップするため、ボスの攻撃を凌ぎながら敵を倒して回復するスリリングな戦いが可能。
  - **4段階の形態進化**: 時間経過（150秒/300秒/450秒等）に合わせて「マッドピーチ」→「アビスピーチ」→「ベノムピーチ」→「桃皇帝ゼノピーチ」へと強化・変色。
- **ゲームバランス・戦闘設計の全面刷新（後半の耐久インフレ解消＆戦線の動的化）**:
  - **敵HP耐久曲線のマイルド化**: 終盤の急激なHP爆発を抑制（`1 + t/150 + (t/270)^1.32`）。3分時点で約2.8倍、5分時点で約4.1倍、10分時点で約7.7倍とし、育成した攻撃パッシブや武器で中盤以降もしっかり雑魚をなぎ倒せる爽快感を確保。
  - **敵スポーンの波（クラスター化）**: 敵の約65%が5〜9秒ごとに変化する主攻勢方向からまとまって進軍、35%が全方位散発。画面内に自然な「密度の濃い戦線」と「敵が薄い逃げ道」が生まれ、立ち回りの楽しさが向上。
  - **包囲ウェーブの脱出スリット**: 75秒ごとの全周リング湧きイベント（「敵の大群が迫る！」）に約50度の切れ目（スリット）を設け、見極めて脱出できるプレイヤースキル要素を導入。
  - **進行方向への突破口（火炎ブレスの強化）**: 貫通数を大幅増（Lv1:2体、Lv2:3体、Lv4:4体、Lv6:5体、Lv8:6体）。さらにノックバック力を160→340（約2.1倍）へ強化し、正面の群れを押し戻して自力で脱出ルートをこじ開けられる性能へ。
  - **お漏らしボム（うんち）の二段階起爆＆逆ノックバック防止**: 直踏み時（100%集中大ダメージ＋0.45秒無敵付与＋敵弾消去）と、時限自動爆発（威力40%・範囲1.35倍の広域牽制）の二段階化。自機とボムの間に敵がいる際に敵が自機側へ吹き飛ぶ事故を防ぐ安全リダイレクト（`poopBlastDir`）を実装。
- **操作性・快適性・UI（QoL）の向上**:
  - **経験値ジェムの自機方向ポップ物理**: 敵撃破時にジェムが自機方向へ勢いよく弾む（初速260〜380px/s＋摩擦減衰で20〜45pxポップ）。後退しながら倒した後方のジェムもスムーズに手元に近づき、大回りマラソンの負担を大幅解消。
  - **基礎マグネット範囲の拡大**: 80px → 100px へ拡大し、吸引の快適性を向上。
  - **リザルト＆ポーズ画面の装備スロット一覧**: ゲームクリア／ゲームオーバー時のリザルトカードおよびポーズ画面に、左上HUDと同デザインの「取得装備（武器・パッシブ）スロット一覧」を表示（MAX発光枠・ツールチップ付き）。
  - **操作ショートカットの拡充**: `Space` キーでのポーズ／再開に対応。またタイトル画面のスタートやゲームオーバー画面の再挑戦を `Space` または `Enter` キーのみで即座に実行可能に。
  - **スマホ用ポーズボタン**: 画面右下に一時停止ボタン（⏸）を追加。タッチ操作でも手軽にポーズ／再開可能。
- **演出・フィードバック・音響の強化**:
  - **画面外ボスの方向インジケーター**: ボスが画面外にいる時、画面端に接近方向を指す赤い警告三角矢印（⚠）と距離メーター（例: `⚠ 65m`）をパルス表示。
  - **黄金無敵オーラバリア**: お漏らしボム直踏み起爆時、自機の周囲に黄金の二重光彩オーラバリアを展開。無敵突進の爽快感を視覚的に強調。
  - **HP満タン時の肉取得ボーナス**: HP全快状態で肉を拾うと無駄にならず、経験値獲得 ＋ 4秒間の移動速度30%ブースト（足元に光芒パーティクル）が発動。
  - **聖光オーラのクール短縮連動**: 加速装置パッシブ（`P.cd`）がオーラのダメージ間隔（`0.35 * P.cd`）に連動し、連続ヒット速度が向上。
  - **メカアームレーザーのエフェクトシャープ化**: 持続ライフを0.16秒に短縮し、純白の芯とシアンの閃光が急速に細く収束する鋭い「一閃照射」エフェクトに刷新。
  - **ボス戦＆ピンチ時の動的BGM演出**: ボス出現中または自機HP35%以下の危機的状況で、BGMテンポが約20%アップ。ドラム倍速刻みとベースオクターブ連打による緊迫戦闘ビートへ動的に変化。
- **パフォーマンス最適化（カクツキ解消）**:
  - 敵描画ソート配列の再利用（GCフリー化）や、フォントパースキャッシュによる毎フレームの文字列生成削減を実施。
  - 状態遷移時に被弾画面揺れが減衰せず残り続ける不具合を解消。
- **アーキテクチャの完全整備**:
  - Canvas単一配布用（`kesmon_survivor_canvas.html`）と、保守・開発用のモジュール分割版（`index.html` + `game.js` + `style.css`）の両方を完全マージ。

#### 🔊 v0.3.0 (2026-10-28) — サウンド・ききボイス（音声合成）実装版
- **ボイス演出の追加**:
  - AI音声合成（GPT-SoVITS）を用いて生成されたオリジナルボイスをゲームに組み込み。
  - ゲームスタート時（「ケスモンサバイバー、スタート！」等のボイス）および第1形態からの進化時に専用ボイスが再生。
- **オーディオエンジンの強化**:
  - Web Audio API を活用したリッチなBGMコード進行およびアルペジオ再生。
  - 攻撃ヒット音、レベルアップファンファーレ、進化時のドラマチックなSE。
  - Mキーまたは画面端のスピーカーアイコンでのミュート切り替え。

#### 💩 v0.2.0 (2026-10-27) — 操作性改善・視認性向上・うんちボム追加版
- **新スキル「お漏らしボム（うんち）」追加**:
  - 一定時間ごとに進行方向の逆（背後）にうんちを投下。
  - プレイヤー自身が踏むことで**集中爆破＋一時的な無敵時間**が発生し、敵の大群に囲まれた際の緊急回避・打開手段として機能。
  - 放置して一定時間経過した場合も広範囲自爆を行い敵を一網打尽にする。
- **操作性・攻撃方向の最適化**:
  - 火炎ブレス弾がプレイヤーの向いている進行方向に正確に発射されるよう調整。
- **視認性の劇的改善**:
  - コウモリ敵が重なった際に見失わないよう、スプライト外周に**ネオングリーンの縁取り（アウトライン）**を追加。
  - ドロップアイテム（経験値ジェム等）の光彩エフェクトを強調し、背景に埋もれないよう改良。
- **ゲームバランス調整**:
  - 移動速度アップのパッシブスキルを廃止し、敵との距離感や位置取りの重要度を強化。

#### 🌱 v0.1.0 (2026-10-26) — 初期プロトタイプ
- **ケスモンサバイバーの誕生**:
  - ヴァンパイアサバイバーズをオマージュしたトップダウン2D全方位サバイバル。
  - 市松模様背景の元画像から高精度なキャラクター切り抜きを行い、4枚の進化グラフィックを適用。
  - レベル8、18、30到達時に劇的に姿と能力が変わる「形態進化システム」を構築。
  - 単一のHTMLファイル（Canvas版）で誰でもブラウザひとつですぐにプレイ可能な設計。

主人公ケスモンは、経験値を集めてレベルアップすることで姿と能力が進化します！

```
【第1形態：幼体】           【第2形態：成長体】           【第3形態：改造体】           【第4形態：究極体】
   ケスモン        ──Lv8──>   ドラグケスモン   ──Lv18──>   オーバードケスモン ──Lv30──>    ホスピスケスモン
 (初期サイズ: 74)             (サイズ: 88)                 (サイズ: 96)                  (サイズ: 110)
 [固有武器: 火炎ブレス]       [獲得: 竜尾スラッシュ]        [獲得: 回転メカソー]          [獲得: 聖光オーラ]
```

## 🗺️ ステージ＆ボス

### 🌲 STAGE 1：機械の苔森
- **ボス**: **機皇帝メカイザー軍団**
- 深い森と苔むした機械文明の遺跡が広がるステージ。四方から押し寄せる大群を突破せよ！

- **ボス**: **×口桃型ボス軍団**
  - **マッドピーチ** (初期ボス)
  - **アビスピーチ** (第2形態)

  - ボスが召喚する最大5体の「ミニピーチ」を倒すと**必ず回復ハート**がドロップするので、回復ソースとして利用しながら口を狙おう！

## 🎮 操作方法

- **移動**: `W`, `A`, `S`, `D` または `↑`, `←`, `↓`, `→` キー
  - *スマートフォン・タブレット*: 画面をスワイプ / ドラッグで直感的に移動可能
- **攻撃**: 自動（オートエイム＆オートアタック）
- **決定 / 即時スタート・リトライ**: `Space` または `Enter` キー（タイトル画面での開始やリザルト画面での再挑戦）
- **ポーズ (一時停止)**: `Space` / `Esc` / `P` キー または 画面右下の一時停止ボタン（⏸）
- **サウンド ON/OFF**: `M` キー または 画面右下のスピーカーアイコン（🔊）
